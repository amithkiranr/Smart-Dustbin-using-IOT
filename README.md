# Smart-Dustbin-using-IOT
"Smart Dustbin using IoT" is an automatic waste bin that opens and closes its lid when a hand is detected nearby using an 'ultrasonic sensor'. A 'servo motor' controls the lid’s movement, making it a touch-free and hygienic solution. The system is powered by 'Arduino (or ESP32)' and can be extended with 'IoT features' to monitor usage .
